# Практика YeaHub "Список вопросов"

### Обзор

- Интро
- Технологии
- Figma
- Проект

**Интро**

Цель проекта:
Разработать учебное веб-приложение на React для отображения списка вопросов с возможностью поиска, фильтрации и пагинации, используя публичное API. Пока без перехода на страницу подробного вопроса.

**Технологии:**

- React
- Vite
- Fetch/Axios
- Работой с API
- Состоянием и хуками
- Базовой архитектурой фронтенд-проекта
